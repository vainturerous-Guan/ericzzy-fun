# game-data · 游戏化与成就数据

本目录存放 ericzzy.fun 三个频道的**静态配置数据**（奖励映射、成就定义、题库覆盖统计），由站点页面按需 fetch。

## 频道与奖励规则（第一期：仅数值/图鉴收集，不改变答题规则）

- `monster` 小学生·打怪版（男孩版）：数学→武器，语文→衣服（功能加成仅数值展示），英语→鞋子，其他学科→武功秘籍。
- `dressup` 小学生·打扮版（女孩版）：数学→项链与头冠，语文→衣服（好看的），英语→鞋子，其他学科→配饰。
- `teen` 中学生·成就版：只有本机成就称号，无打怪和打扮内容，不分男女。跨用户排名需等登录注册机制上线后再做。

## 进度存储

打怪/打扮/成就的运行时进度和孩子档案一样保存在浏览器 localStorage，不上传、无账号。清除浏览器数据前需导出备份（档案页提供导出/导入）。本目录只放静态配置，不放运行时数据。

## 文件

- `rewards.json`：各学科在各频道下的奖励类别定义。
- `coverage.json`：题库覆盖统计（2026-11-13 由 `knowledge-graph/data/*.json` 计算），用于设计"练完得奖励"的门槛。英语一、二年级暂无题目，频道页已做空态提示，待后续补充基础课内容。
